# データベース設計

# 1. exercise_master テーブル

## 目的

部位 → 種目のマスタ

## Key設計

```
Table: exercise_master

PK = PART#<部位>
SK = EXERCISE#<種目>
```

---

## 属性

| 属性 | 説明 |
| --- | --- |
| PK | PART#CHEST |
| SK | EXERCISE#BENCHPRESS |
| exercise_name | 表示用名称 |
| created_at | 作成日時 |
| updated_at | 更新日時 |
| created_by | 作成ユーザ |
| updated_by | 更新ユーザ |

---

## データ例

| PK | SK | exercise_name | created_at | updated_at | created_by | updated_by |
| --- | --- | --- | --- | --- | --- | --- |
| PART#CHEST | EXERCISE#BENCHPRESS | Bench Press | 2026-03-10T10:00 | 2026-03-10T10:00 | admin | admin |
| PART#CHEST | EXERCISE#INCLINE_PRESS | Incline Press | 2026-03-10T10:00 | 2026-03-10T10:00 | admin | admin |
| PART#BACK | EXERCISE#DEADLIFT | Deadlift | 2026-03-10T10:00 | 2026-03-10T10:00 | admin | admin |

---

## 取得例

# 2. muscle_records テーブル

## 目的

ユーザの筋トレログ管理

---

## Key設計

```
Table: muscle_records

PK = USER#<userId>
SK = DATE#<yyyymmdd>#EXERCISE#<種目>#SET#<番号>
```

---

## 属性

| 属性 | 説明 |
| --- | --- |
| PK | USER#1 |
| SK | DATE#20260310#EXERCISE#BENCHPRESS#SET#1 |
| exercise | 種目 |
| weight | 重量 |
| reps | 回数 |
| memo | メモ |
| created_at | 作成日時 |
| updated_at | 更新日時 |
| created_by | 作成ユーザ |
| updated_by | 更新ユーザ |

---

## データ例

| PK | SK | weight | reps | created_at | updated_at | created_by | updated_by |
| --- | --- | --- | --- | --- | --- | --- | --- |

# 3. Queryパターン

## ユーザの全履歴

```
PK = USER#1
```

---

## ある日のトレーニング

```
PK = USER#1
SK begins_with DATE#20260310
```

---

## ある日の特定種目

```
PK = USER#1
SK begins_with DATE#20260310#EXERCISE#BENCHPRESS
```

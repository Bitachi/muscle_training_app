# 要件定義(MVP1)

## 

# 1. MVP 機能要件（Functional Requirements）

## ① トレーニング記録

ユーザーはトレーニングを記録できる。

### 記録の階層

```
部位
  ↓
トレーニング種別
  ↓
トレーニングセッション（日時）
  ↓
セット
```

例

```
胸
  └ ベンチプレス
        └ 2026/03/07 10:30
              ├ 80kg 5rep
              ├ 75kg 8rep
              └ 70kg 10rep
```

---

## ② セット情報

1セットごとに記録する情報

| 項目 | 内容 |
| --- | --- |
| 重量 | kg |
| 回数 | rep |
| メモ | 自由記述 |
| 推定1RM | 重量・回数から計算 |

### 1RM計算式（一般的）

```
1RM = weight × (1 + reps / 30)
```

例

```
80kg × 5rep
→ 93kg (推定)
```

※これはDB保存ではなく **Lambdaで計算する**

---

## ③ トレーニング一覧表示

ユーザーは記録したトレーニングを閲覧できる。

表示例

```
2026-03-07
胸
ベンチプレス

80kg × 5
75kg × 8
70kg × 10
```

将来的には

- 日付順
- 種目別
- 部位別

などで表示。

# 2. マスタ管理（重要）

> 部位・トレーニング種別はDBで管理
> 

つまり

### 部位マスタ

```
胸
背中
脚
肩
腹
腕
```

### トレーニング種別

```
ベンチプレス
インクラインベンチ
スクワット
デッドリフト
ラットプルダウン
```

関係

```
部位 1
 ↓
トレーニング種別 N
```

例

```
胸
 ├ ベンチプレス
 ├ インクラインベンチ
 └ ダンベルフライ
```

ユーザーは

- 追加
- 編集
- 削除

できる。
